# abnormalhq/homebrew-tap

[![Audit](https://github.com/abnormalhq/homebrew-tap/actions/workflows/audit.yml/badge.svg)](https://github.com/abnormalhq/homebrew-tap/actions/workflows/audit.yml)

The [Homebrew](https://brew.sh/) tap for [Abnormal Mail](https://abnormalhq.com/download/), the desktop mail client for Abnormal mailboxes, and for `abnormal`, the command-line client for the Abnormal management API.

| Cask            | App           | Requires                                    |
| --------------- | ------------- | ------------------------------------------- |
| `abnormal-mail` | Abnormal Mail | macOS 11 or later (Apple Silicon and Intel) |

| Formula    | Command    | Requires                                         |
| ---------- | ---------- | ------------------------------------------------ |
| `abnormal` | `abnormal` | Node.js (installed by Homebrew); macOS and Linux. Arrives with the first CLI release ([see below](#arrives-with-the-first-cli-release)) |

## Install

```bash
brew install --cask abnormalhq/tap/abnormal-mail
```

Or tap once and install by name:

```bash
brew tap abnormalhq/tap
brew install --cask abnormal-mail
```

### First launch

Abnormal Mail is not signed with an Apple Developer ID yet, so macOS blocks its first launch. Open System Settings > Privacy & Security and click "Open Anyway", or run:

```bash
xattr -dr com.apple.quarantine "/Applications/Abnormal Mail.app"
```

## Update

```bash
brew upgrade --cask abnormal-mail
```

## Uninstall

```bash
brew uninstall --cask abnormal-mail
```

To also delete the app's local data (`~/Library/Application Support/abnormal-mail`):

```bash
brew uninstall --zap --cask abnormal-mail
```

## The `abnormal` command

```bash
brew install abnormalhq/tap/abnormal
abnormal login        # asks for an API key and saves it in ~/.config/abnormal/config.json
abnormal whoami
abnormal mailboxes list --domain example.com --output table
```

Update with `brew upgrade abnormal`, remove with `brew uninstall abnormal` (the saved key stays in `~/.config/abnormal/config.json`; `abnormal logout` before uninstalling deletes it). The commands, options and exit codes are described in [docs/sdks.md](https://github.com/abnormalhq/mail/blob/main/docs/sdks.md) in abnormalhq/mail.

### Arrives with the first CLI release

There is no `Formula/abnormal.rb` here yet. A formula can only pass `brew audit` (and only install) once its tarball can be downloaded, and there has been no `cli-v<version>` release of abnormalhq/mail yet. The first one adds the formula, and each later one rewrites it with the new version and the tarball's SHA-256: it is generated by `cli/scripts/formula.mjs` and committed here by the release workflow (`.github/workflows/cli-release.yml`), the same way the cask is updated. Change the formula there, not here.

Before that release:

- **A public download.** Homebrew downloads the tarball without signing in, and abnormalhq/mail is private, so the tarball must be served from a public place (for example `downloads.abnormalhq.com`, like the desktop app), and the URL in `cli/scripts/formula.mjs` must point there.
- **A way in for the release workflow.** `main` here only takes changes through pull requests, so the release app's direct push of a new version is refused (the desktop 0.11.1 release hit this). The release workflows must open a pull request instead, or the rule must let the release app through.

[`audit.yml`](.github/workflows/audit.yml) audits every formula and cask in the tap, so the formula is checked from its first release on. Once it is here, also add `brew install abnormalhq/tap/abnormal` and `brew test abnormal` to the workflow (the test runs `abnormal --version`).

## How the cask is updated

[`Casks/abnormal-mail.rb`](Casks/abnormal-mail.rb) is generated, not written by hand. Each desktop release in [abnormalhq/mail](https://github.com/abnormalhq/mail) uploads the `.dmg` to `downloads.abnormalhq.com`, then `desktop/packaging/release.py` rewrites the cask with the new version and SHA-256 and the release app commits it here. Hand edits to the cask are overwritten by the next release, so change the template in `release.py` instead. (0.11.1 was brought in by hand, through a pull request, because the release's own push was refused: see [above](#arrives-with-the-first-cli-release).)

Every pull request and every push to `main`, release commits included, runs [`audit.yml`](.github/workflows/audit.yml) on macOS: `brew style`, `brew audit --cask --strict --online`, and a real install followed by `brew uninstall --zap`.

The cask's `livecheck` reads <https://downloads.abnormalhq.com/desktop/latest.json>, so `brew livecheck abnormal-mail` reports the latest published version.
